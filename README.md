# Kashmir Travelify CRM – iOS

Native iOS WKWebView application for:

`https://crm.kashmirtravelify.com/newcrm/`

## Open and run on Mac

1. Extract this ZIP.
2. Open `KashmirTravelifyCRM.xcodeproj` in Xcode.
3. Select the **KashmirTravelifyCRM** target.
4. Open **Signing & Capabilities**.
5. Select your Apple Developer Team.
6. Change the Bundle Identifier if Xcode reports that it is already in use.
7. Select an iPhone simulator or connected iPhone and press **Run**.

## Archive / TestFlight

In Xcode select **Any iOS Device (arm64)**, then use **Product → Archive**. From Organizer choose **Distribute App**.

## Included support

- Persistent login/session cookies
- Camera, photo library and document upload through HTML file fields
- CRM links and popups inside the app
- Phone, email, SMS and WhatsApp external links
- Back/forward swipe navigation
- JavaScript alerts and confirmations
- Loading progress and retry alert
- iPhone and iPad layouts

Deployment target: iOS 15.0+
